## Codebase Patterns
- Godot 4.x scene files (.tscn) use format=3 and uid for resources
- Use `RigidBody2D` with `physics_material_override` for ball physics
- All cross-system communication via EventBus signals (defined in scripts/autoloads/)
- Physics values loaded from JSON data files (data/pegs/peg_definitions.json)
- Shaders use canvas_item for 2D effects, apply via ShaderMaterial to ColorRect nodes
- Debug overlays extend Node2D for _draw() methods, placed inside CanvasLayer
